# v2.2.2 — Home season record

The Home season summary now shows **Wins, Draws and Losses** alongside league position, points and recent form. Separate text labels and green/neutral/red totals make the record easy to scan. Phones use a full-width record row; larger screens show it beside the other summary fields.

The display reads the existing committed league standings. It shows 0–0–0 before kickoff, counts home and away results across the whole current season, excludes the pending match, and resets when the season’s fixtures reset. It introduces no saved fields and changes no save-writing behavior, player data or match outcomes.

Validation covers a fresh season, a 2-win/1-draw/1-loss record with a pending match, and a new-season reset. Production-browser checks cover fresh and played careers at 320px, 390px, 430px and desktop widths, including record visibility, layout bounds, reload and runtime errors.

Release checks: **258 tests passed, zero failures**. TypeScript/Vite production build and appearance-data consistency passed. All eight production-browser scenarios passed with zero runtime errors. The existing large-bundle advisory remains.
